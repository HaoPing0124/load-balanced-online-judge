题目描述
给定一个整数数组 nums 和一个整数 target，请在数组中找到两个不同位置的元素，使它们的和等于 target，并返回这两个元素的下标。

每组数据保证恰好存在一组有效答案，同一个元素不能重复使用。两个下标的返回顺序不限。

函数要求
vector<int> twoSum(vector<int>& nums, int target)

输入示例 1
nums = [2, 7, 11, 15], target = 9

输出示例 1
[0, 1]

示例说明
nums[0] + nums[1] = 2 + 7 = 9。

输入示例 2
nums = [3, 2, 4], target = 6

输出示例 2
[1, 2]

数据范围
2 <= nums.size() <= 10000
-1000000000 <= nums[i] <= 1000000000
-1000000000 <= target <= 1000000000

资源限制
CPU 时间：1 秒
内存限制：128 MB（131072 KB）

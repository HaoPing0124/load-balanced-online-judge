题目描述
给定一个整数数组 nums 和整数 k，请统计数组中元素和恰好等于 k 的连续子数组数量。

子数组必须是原数组中连续且非空的一段。

函数要求
int subarraySum(vector<int>& nums, int k)

输入示例 1
nums = [1, 1, 1], k = 2

输出示例 1
2

输入示例 2
nums = [1, 2, 3], k = 3

输出示例 2
2

数据范围
1 <= nums.size() <= 20000
-1000 <= nums[i] <= 1000
-10000000 <= k <= 10000000

资源限制
CPU 时间：1 秒
内存限制：128 MB（131072 KB）

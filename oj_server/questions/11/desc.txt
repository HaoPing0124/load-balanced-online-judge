题目描述
给定一个整数数组 nums 和窗口大小 k。窗口最初覆盖数组最左侧的 k 个元素，之后每次向右移动一格。

请返回窗口每个位置中的最大值。

函数要求
vector<int> maxSlidingWindow(vector<int>& nums, int k)

输入示例 1
nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3

输出示例 1
[3, 3, 5, 5, 6, 7]

输入示例 2
nums = [1], k = 1

输出示例 2
[1]

数据范围
1 <= nums.size() <= 100000
-10000 <= nums[i] <= 10000
1 <= k <= nums.size()

资源限制
CPU 时间：2 秒
内存限制：128 MB（131072 KB）

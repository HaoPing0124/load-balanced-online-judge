题目描述
给定字符串 s 和 t，请在 s 中找到一个最短连续子串，使该子串包含 t 中的全部字符及其出现次数。

若不存在满足条件的子串，返回空字符串。测试数据保证最短答案唯一。

函数要求
string minWindow(string s, string t)

输入示例 1
s = "ADOBECODEBANC", t = "ABC"

输出示例 1
"BANC"

输入示例 2
s = "a", t = "a"

输出示例 2
"a"

输入示例 3
s = "a", t = "aa"

输出示例 3
""

数据范围
1 <= s.size(), t.size() <= 100000
s 和 t 由英文字母组成

资源限制
CPU 时间：2 秒
内存限制：128 MB（131072 KB）

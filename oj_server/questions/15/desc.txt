题目描述
给定一个整数数组 nums 和非负整数 k，请把数组整体向右轮转 k 个位置。

要求直接修改原数组。

函数要求
void rotate(vector<int>& nums, int k)

输入示例 1
nums = [1, 2, 3, 4, 5, 6, 7], k = 3

输出示例 1
[5, 6, 7, 1, 2, 3, 4]

输入示例 2
nums = [-1, -100, 3, 99], k = 2

输出示例 2
[3, 99, -1, -100]

数据范围
1 <= nums.size() <= 100000
-2147483648 <= nums[i] <= 2147483647
0 <= k <= 100000

资源限制
CPU 时间：1 秒
内存限制：128 MB（131072 KB）

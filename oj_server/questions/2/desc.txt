题目描述
给定一个字符串数组 strs，请把互为字母异位词的字符串放入同一组，并返回所有分组。

字母异位词由相同字符组成，每个字符出现次数也完全相同，只是排列顺序可能不同。各组之间以及组内字符串的返回顺序不限。

函数要求
vector<vector<string>> groupAnagrams(vector<string>& strs)

输入示例 1
strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

输出示例 1
[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]

输入示例 2
strs = [""]

输出示例 2
[[""]]

数据范围
1 <= strs.size() <= 10000
0 <= strs[i].size() <= 100
strs[i] 只包含小写英文字母
所有字符串的总长度不超过 100000

资源限制
CPU 时间：2 秒
内存限制：128 MB（131072 KB）

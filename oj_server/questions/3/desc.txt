题目描述
给定一个未排序的整数数组 nums，请返回其中最长连续整数序列的长度。

连续序列中的相邻数字相差 1，这些数字在原数组中不要求相邻。请设计平均时间复杂度为 O(n) 的算法。

函数要求
int longestConsecutive(vector<int>& nums)

输入示例 1
nums = [100, 4, 200, 1, 3, 2]

输出示例 1
4

示例说明
最长连续序列为 [1, 2, 3, 4]。

输入示例 2
nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]

输出示例 2
9

数据范围
0 <= nums.size() <= 100000
-1000000000 <= nums[i] <= 1000000000

资源限制
CPU 时间：1 秒
内存限制：128 MB（131072 KB）

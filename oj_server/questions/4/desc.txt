题目描述
给定一个整数数组 nums，请把数组中的所有 0 移动到末尾，同时保持所有非零元素原有的相对顺序。

要求直接修改原数组，不能通过返回一个新数组完成。

函数要求
void moveZeroes(vector<int>& nums)

输入示例 1
nums = [0, 1, 0, 3, 12]

输出示例 1
[1, 3, 12, 0, 0]

输入示例 2
nums = [0]

输出示例 2
[0]

数据范围
1 <= nums.size() <= 10000
-2147483648 <= nums[i] <= 2147483647

资源限制
CPU 时间：1 秒
内存限制：128 MB（131072 KB）

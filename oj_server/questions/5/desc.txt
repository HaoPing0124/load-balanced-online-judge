题目描述
给定一个长度为 n 的非负整数数组 height。第 i 个数字表示位于横坐标 i 处的一条竖线高度。

任选两条竖线作为容器的左右边界，容器能装的水量等于两条线中较矮者乘以它们之间的距离。请返回可以得到的最大水量。

函数要求
int maxArea(vector<int>& height)

输入示例 1
height = [1, 8, 6, 2, 5, 4, 8, 3, 7]

输出示例 1
49

输入示例 2
height = [1, 1]

输出示例 2
1

数据范围
2 <= height.size() <= 100000
0 <= height[i] <= 10000

资源限制
CPU 时间：1 秒
内存限制：128 MB（131072 KB）

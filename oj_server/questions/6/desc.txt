题目描述
给定一个整数数组 nums，请找出所有由三个不同下标组成的三元组，使三个数之和等于 0。

答案中不能包含数值完全相同的重复三元组，三元组以及答案列表的返回顺序不限。

函数要求
vector<vector<int>> threeSum(vector<int>& nums)

输入示例 1
nums = [-1, 0, 1, 2, -1, -4]

输出示例 1
[[-1, -1, 2], [-1, 0, 1]]

输入示例 2
nums = [0, 1, 1]

输出示例 2
[]

数据范围
3 <= nums.size() <= 3000
-100000 <= nums[i] <= 100000

资源限制
CPU 时间：2 秒
内存限制：128 MB（131072 KB）

题目描述
给定一个非负整数数组 height，每个元素表示宽度为 1 的柱子高度。下雨后，柱子之间可能形成凹槽，请计算这些柱子总共能够接住多少单位的雨水。

函数要求
int trap(vector<int>& height)

输入示例 1
height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]

输出示例 1
6

输入示例 2
height = [4, 2, 0, 3, 2, 5]

输出示例 2
9

数据范围
1 <= height.size() <= 20000
0 <= height[i] <= 100000

资源限制
CPU 时间：1 秒
内存限制：128 MB（131072 KB）
